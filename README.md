# Salma Birthday Website

A premium interactive birthday website built with React, Vite, Framer Motion,
React Icons, and Canvas Confetti.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Personalize

- Add photos to `public/images` using the paths already referenced by the app:
  `/images/photo1.jpg`, `/images/photo2.jpg`, and so on.
- Add the local song/video file at `public/videos/song.mp4`.
- Edit birthday copy and messages in `src/assets/birthdayData.js`.

The app includes fallback visuals if placeholder photos are missing during
development.
